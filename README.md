# Chess Search Mathematics

本仓库研究国际象棋及相关有限双人零和博弈中**搜索算法的数学基础**：极大极小界限、证明驱动搜索、状态复用、搜索空间压缩与有限预算分配。目标是形成清晰的数学命题、严格证明、有效反例及可复核的算法界限。

研究遵循 **先数学，后工程**。这里保存理论成果；独立的 EvilChess 引擎负责具体实现、性能测试与硬件优化。两者可以互相借鉴，但分别维护。

## 当前研究方向

1. **严格搜索与证明证书：** Alpha-Beta 界限、AND/OR 证明、最优走法证书及其规模。
2. **搜索空间的结构：** 转置图、状态等价、可证明的分支排除与子问题复用。
3. **计算预算分配：** 给定搜索成本时的最优性条件、误差界、近似保证与反例。
4. **特殊局面的精确算法：** 在明确限制的局面类中求取可证明的搜索或复杂度结果。

完整问题、范围和首轮任务见 [RESEARCH_PLAN.md](RESEARCH_PLAN.md)。协作规范见 [AGENTS.md](AGENTS.md)。
